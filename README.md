# SMS-рассылка через Android-телефон

Панель на компьютере управляет рассылкой, SMS уходят с SIM-карты Android-телефона,
подключённого по USB-кабелю или Wi-Fi.

```
Панель + база (SQLite)  ──HTTP──▶  Android: SMS Gateway  ──▶  SIM  ──▶  SMS
                    по USB (adb forward) или Wi-Fi
```

## Что здесь

| Папка | Что внутри |
|---|---|
| [`panel/`](panel) | само приложение: импорт базы, шаблоны, очередь отправки, отчёты |
| [`build/`](build) | сборка автономного приложения — `.app` для macOS, `.exe` для Windows |
| [`.github/workflows/`](.github/workflows) | сборка Windows `.exe` на раннере GitHub |

Подробности — в [panel/README.md](panel/README.md) и [build/README.md](build/README.md).

## Windows `.exe`

PyInstaller не умеет кросс-компиляцию, поэтому `.exe` собирается на Windows.
Проще всего — здесь, в Actions:

1. Вкладка **Actions** → **Сборка Windows exe** → **Run workflow**.
2. Дождаться зелёной галочки (около двух минут).
3. Внизу страницы запуска скачать артефакт **smsblast-windows** — внутри
   `smsblast.exe`, один файл, Python на машине не нужен.

Workflow не просто собирает: он запускает готовый `.exe`, дожидается подъёма
панели и проверяет, что страницы отвечают `200`. Если сборка сломана — она
не станет зелёной.

Для режима USB на Windows нужен `adb` (Android Platform Tools от Google)
в `PATH` — он не встраивается в `.exe`.

## Чего в репозитории нет и не должно быть

База контактов, загруженные файлы и `.env` сюда не попадают: в базе лежат
телефоны получателей и пароль от шлюза. Исходники копируются в репозиторий по
белому списку (см. `sync.sh`), а `.gitignore` перекрывает это вторым слоем.
