Подключение к телефону

Логин и пароль берутся из приложения SMS Gateway на телефоне: раздел Local Server.

Порт шлюза пробрасывается через кабель на 127.0.0.1. Wi-Fi не нужен вовсе: телефон может сидеть на мобильном интернете и попутно заряжаться.

«Подготовить телефон» выдаёт разрешение на отправку SMS, снимает ограничение экономии батареи и запускает шлюз — брать телефон в руки не нужно.

По умолчанию для новых рассылок

Тестовое SMS

Отправьте одно сообщение себе, прежде чем запускать рассылку на всю базу.

Настройка телефона

  1. Установите на Android приложение SMS Gateway for Android (APK со страницы релизов проекта).
  2. Выдайте разрешение Отправка SMS.
  3. Включите переключатель Local Server и нажмите Offline.
  4. Перепишите отсюда логин и пароль в поля слева.
  5. Отключите оптимизацию батареи для приложения, иначе Android «усыпит» шлюз посреди рассылки.

Для подключения по кабелю

Руками на телефоне делается только это, и только один раз:

  1. Настройки → О телефоне → семь раз нажать Номер сборки, чтобы открыть режим разработчика.
  2. Настройки → Для разработчиков → включить Отладка по USB.
  3. Подключить кабель и нажать на экране телефона Разрешить отладку по USB.
  4. В приложении-шлюзе один раз включить Local Server и переписать отсюда логин с паролем — состояние запоминается, дальше панель поднимает шлюз сама.

Дальше — кнопка Подготовить телефон слева: разрешения, батарея и запуск шлюза делаются с компьютера. Перед каждой рассылкой панель поднимает шлюз сама, если он не запущен.
